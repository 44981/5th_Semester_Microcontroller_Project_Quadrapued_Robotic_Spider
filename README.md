**Quadruped Robotic Spider**

A 5th semester microcontroller project: a quadruped (four-legged) spider robot built and programmed to walk using servo-driven legs.

📁 Repository Contents

📊 Quadruped Spider Robot_Slide.pptx

Presentation slides covering the project design, working principle, and results.

🦿 quadruped_spider_robot_code.ino

Main Arduino code controlling the quadruped spider robot's walking gait and movement.

🔧 quadruped_legs_correction_Code.ino

Arduino code for calibrating individual leg servo positions to fix alignment issues in the robot's gait.

🛠️ How It Works

The quadruped spider robot uses servo motors on each of its four legs, driven by the Arduino microcontroller. The main program (quadruped_spider_robot_code.ino) generates the walking gait, while the leg correction code (quadruped_legs_correction_Code.ino) is used separately to calibrate each servo's neutral position so all four legs move symmetrically and accurately.
